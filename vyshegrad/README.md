# Вышеградский Помощник: полная инструкция

В папке два куска:
- `site/index.html` : мини-апп (его открывает Telegram)
- `bot/` : бот для Telegram и Discord с общей базой

## Порядок запуска
1. **Сайт.** Выложите `site/index.html` на GitHub Pages или Netlify. Получится https-адрес, например `https://ник.github.io/vysh/`. Это `WEBAPP_URL`.
2. **Telegram-бот.** В @BotFather: `/newbot`, сохраните токен (`TG_TOKEN`).
3. **Discord-бот.** discord.com/developers/applications -> New Application:
   - Bot -> Reset Token -> токен в `DC_TOKEN`;
   - General Information -> Application ID это `DISCORD_CLIENT_ID`;
   - OAuth2 -> Redirects -> добавьте адрес сайта из шага 1 (точно, как есть);
   - OAuth2 -> URL Generator -> scopes `bot` и `applications.commands` -> откройте ссылку и добавьте бота на сервер.
4. **ID сервера.** В Discord: Настройки -> Расширенные -> режим разработчика. ПКМ по серверу -> Копировать ID сервера (`DISCORD_GUILD_ID`).
5. **Хостинг бота** (Railway или Render, тип Web Service, команда запуска `python bot.py`). Загрузите папку `bot/`, в переменные окружения внесите всё из `.env.example`. Публичный адрес сервиса + `/api/me` это `API_URL`.
6. **Меню бота.** В Telegram откройте своего бота, отправьте `/start`, нажмите «Открыть помощника».

## Что править в index.html
- `DONATE_URL`: ссылка на монетизацию.
- `DONATE`: цены, названия и пункты пакетов.
- `STAFF.admins`: Discord-ники друзей-админов.
- `ROLE_NAMES`: ID роли -> название (по желанию).
Client ID, ID сервера и адрес API приложение получает от бота, в файл их вписывать не нужно.

## Что умеет приложение
- **Кошелёк** (кнопка в шапке): сверху общая сумма. Ниже кожаный кошелёк раскрывается, внутри наличные и банковская карта. Нажимаешь на карту, она вынимается, и появляется «Положить на счёт» (наличные -> карта). Ссылка «Снять наличные со счёта» переключает в обратную сторону. Влеты лежат отдельной строкой. Переводы работают через бота (нужен `API_URL`), бот проверяет подпись Telegram.
- **Фото машины**: у каждой машины в «Имуществе» есть кнопка с камерой. Игрок выбирает свою фотографию, она сохраняется на его телефоне и встаёт в шапку. Сердечко выбирает, какая машина показывается. Если у машины нет фото, админ может задать картинку командой `/addasset ... image:https://...`, иначе рисуется машина по названию.
- **Инфо** (кнопка в шапке): игрок из Roblox (аватар, ник, ID, ссылка на профиль) и данные аккаунта. Игрок привязывает ник сам один раз, дальше сменить его может только администрация (`/roblox`). Ник Roblox не подтверждается кодом, поэтому админам стоит сверять его.

## Команды
- Игрок: `/start`, `/myid`, `/link`, `/history`. В Discord: `/link КОД`, `/balance`.
- Админ в Discord: `/give` (влеты, наличные или карта), `/setjob`, `/setlevel`, `/addasset` (с картинкой по желанию), `/removeasset`, `/roblox`, `/info`, `/buys`.

## Важно
- Токены только в переменных окружения на хостинге. Никому не отправлять и не выкладывать на GitHub.
- Данные игрока обновляются при каждом открытии приложения через кнопку из `/start`.
- Бот знает только то, что внесено командами. Уже имеющееся имущество и деньги нужно внести один раз вручную через `/addasset` и `/give`.
- Если база уже была создана прошлой версией бота, новые поля (наличные, карта, Roblox) добавятся сами при запуске.
